# Messy Name Data Processing with Python

A lightweight Python script designed to automatically clean, filter, and normalize poorly formatted text data. This script demonstrates efficient string manipulation, regular expressions (regex), and list processing workflows.

## 📌 Project Overview

Raw, real-world data generated by AI or user inputs often contains erratic capitalization, unnecessary spaces, special character artifacts, and blank entries. This script automates the cleanup pipeline by processing a messy array of strings into a standardized, production-ready, alphabetically ordered format.

### 🧹 Cleaning Pipeline
1. **Regex Filtering:** Removes all symbols, digits, and special punctuation while preserving letters and intended spaces.
2. **Whitespace Normalization:** Strips external padding and resolves multi-space gaps between words.
3. **Validation & Filtering:** Dynamically flags and discards empty values or entries composed entirely of invalid symbols to prevent execution crashes.
4. **Standardized Casing:** Applies proper capitalization (Title Case) across all multi-word names.
5. **Optimized Sorting:** Aggregates and sorts the finalized names alphabetically in a single operations block.

## 🚀 How It Works

The script condenses data cleaning down into a single, optimized `for` loop to minimize memory usage and overhead.

```python
import re

# ... data loading ...

standard_names = []

for name in messy_names:
    # Remove special characters, lowercase, and strip outer spacing
    stripped = re.sub(r'[^a-zA-Z ]', '', name)
    stripped = stripped.lower()
    stripped = stripped.strip()
    
    # Safely skip empty elements
    if stripped == "":
        continue
        
    # Standardize internal spacing and apply Title Case
    perfect_name = " ".join(stripped.split()).title()
    standard_names.append(perfect_name)

# Sort the final clean dataset once
standard_names.sort()

print(standard_names)
```
